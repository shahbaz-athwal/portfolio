# shbz.me

Personal portfolio and blog. Static [Astro](https://astro.build) site with MDX posts,
build-time OG images via [Takumi](https://takumi.kane.tw), and live Discord/Spotify
presence via [Lanyard](https://github.com/Phineas/lanyard).

```sh
bun install
bun run dev     # http://localhost:4321
bun run check   # types + lint + build
```

No environment variables are required. See [AGENTS.md](AGENTS.md) for structure and conventions.
